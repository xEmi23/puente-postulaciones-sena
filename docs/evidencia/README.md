# Evidencia (capturas manuales del equipo)

Aquí van las capturas que toma una persona del equipo según [docs/entrega/GUIA_CAPTURAS.md](../entrega/GUIA_CAPTURAS.md).

## Cómo nombrarlas

`AAAA-MM-DD_<id>_<descripcion-corta>.png`

- `AAAA-MM-DD`: fecha en que se tomó la captura (no la de hoy si se tomó antes).
- `<id>`: el de la guía (`a1`, `b1`, `d2`, `e3`…).
- `<descripcion-corta>`: minúsculas y guiones, sin tildes ni espacios.

Ejemplos: `2026-11-12_a1_linkedin-borrador-enlace-externo.png`, `2026-11-03_d2_chat-descartar-bot.png`.

## Reglas

- **Sin retoques.** Solo se permite tapar datos sensibles con un recuadro opaco; el pie de figura dice qué se tapó.
- **Nunca** subir: contraseñas, tokens, API Keys, correos o teléfonos de personas reales, nombres de candidatos reales, ni el nombre, NIT, dirección o contactos de la empresa retadora.
- Si una captura no se puede limpiar, no se sube: se describe en texto en [EVIDENCIA_PENDIENTE.md](../entrega/EVIDENCIA_PENDIENTE.md).
